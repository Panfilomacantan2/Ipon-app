# 💰 Ipon — Personal Finance Management App

> A modern personal finance web application for tracking accounts, transactions, savings goals, and personal financial progress.

Ipon is a full-stack personal finance application built to help users organize their money, monitor their spending, manage financial accounts, and work toward savings goals.

This project was built as a hands-on learning project focused on modern full-stack web development, authentication, database design, server-side development, and secure data management.

## ✨ Features

### 🔐 Authentication

- User registration
- User login
- Secure authentication using Supabase Auth
- Protected dashboard routes
- User-specific financial data
- Authentication-aware Server Actions

### 📊 Dashboard

- Total balance overview
- Monthly income
- Monthly expenses
- Savings overview
- Recent transactions
- Savings goal progress
- Financial summary

### 💳 Accounts

Users can manage different types of financial accounts:

- Cash
- Bank accounts
- E-wallets
- Credit cards
- Investment accounts
- Other account types

Each account includes:

- Account name
- Account type
- Currency
- Initial balance
- Description
- User ownership

### 💰 Transactions

Users can track their financial activity:

- Income
- Expenses
- Transaction categories
- Account-based transactions
- Transaction history
- User-specific transactions

### 🎯 Savings Goals

Users can create and track financial goals:

- Goal name
- Description
- Target amount
- Target date
- Goal status
- Progress tracking
